# WhyTime

**打开之前，先想清楚为什么。**

Chrome 扩展 · Manifest V3 · 零依赖 · 纯本地运行

对限制名单里的网站，访问前必须先做一次使用承诺：**目的 + 具体原因 + 接下来去哪 + 时长**。到期自动带离原站。它不禁止你使用，但让每一次使用都有成本、有记录。

## 它解决什么问题

刷起来没完的网站，通常有两类对策，都有短板：

- **硬屏蔽**：一刀切，短期有效，但总有必须用站内资源的时刻；绕不过时人会干脆卸载它。
- **自由使用 + 事后统计**：屏幕时间报告看得很清楚，但看报告是"事后诸葛亮"——刷的时候没有任何东西拦住你。

WhyTime 走第三条路：**不禁止，但要求先承诺**。打开名单里的网站之前，你必须回答"为什么来、具体做什么、做完去哪、要多久"；计时条始终显示你的承诺；到期自动离开；偏离目的时系统会来问你。整个设计的前提是一个诚实的假设：

> **让你刷下去的从来不是网站本身，而是"来都来了"的那一瞬间。** WhyTime 把决策放回"来都来了"之前。

## 功能

### 承诺门（Gate）

- **目的**：工作 / 学习 / 信息查询 / 社交 / 娱乐 / 放松 / 其他
- **具体原因**：必填，旁边有复制按钮（方便去站内搜索框粘贴，让承诺落到动作上）
- **接下来去**：必填。"做完这件事，接下来去__"——空档才是"再刷一会儿"的入口，提前填死它
- **时长**：5/10/15/20/30/45/60 快捷档 + 1–240 分钟自选；提示"拿不准就选短的"

### 顶部计时条（Active）

- 内容 = **你写的具体原因 + 剩余时间**（如 `● 搜索 PsychoPy 定时实验 · 剩余 04:32`），全程可见
- 可拖动，位置记忆（刷新/重启后仍在）；视频全屏时恒居中
- `×` = 主动提前结束，立即带离原站——**提前收场是收益**：Ended 页会告诉你"比计划提前了 N 分钟收场，这就是你省下来的时间"

### 目的对齐检查

使用中系统按自适应间隔（= 计划时长 ÷ 4，收敛在 2–10 分钟）弹窗问你："**现在做的事，和你的目的一致吗？**"

- 一致 → 继续
- 不一致 → 展开偏离原因，可选择"写好了，继续使用"或"不用了，结束使用"

间隔随预算缩短——2 分钟能完成的事设了 15 分钟时，拿到答案后几分钟内系统就会来问你，对抗"预算授予感"。

### 到期与续命摩擦（Expired）

- 到期自动带离原站，进入回顾页：**"期间有没有偏离目的？"**（必答，答完才能操作）
- **默认 0 次续时**——到期就结束。需要续时可在设置里放开 1–3 次
- 开启续时后，每次续时仍要过四道关：写新理由 + "明天的你会怎么看"确认 + 15 秒冷却 + **与最近 3 条理由重复会被直接拒绝**
- 回合间**冷静期**：同一天每多一段已结束的使用，重新开始前多等 2 分钟（上限 10 分钟）——针对"每次承诺都诚实、但连起来刷了一下午"的清醒沉沦

### 身体与作息

- **久坐强制拉伸**：同一场使用连续 40 分钟 → 强制跳转拉伸页（股四头肌 + 小腿，2 分钟倒计时），期间预算冻结、计时暂停
- **睡觉锁定**：宵禁时段（默认 22:00–06:00，可改可关）内名单网站一律指向睡觉页，无任何绕过入口

### 替代动作

设置里填"无目的刷完之后，去这里"（默认：阅读 | 运动，可配多条随机推荐）。到期页与结束页会把它递到你眼前——给"放下手机"一个真实的去处。

### 历史与统计

- 概览：今天实际用时/打开次数/续时次数 + 最近 7 天 + 平均每次计划 vs 实际
- 日报：按网站/用途的当日用时，计划 vs 实际
- 记录表：每场使用的完整明细（保留最近 1000 条）
- 导出：JSON（全字段）/ CSV（Excel 直接打开不乱码），见下文字段说明
- 清空：二次确认，不动进行中的使用

### 站点匹配语义

名单每行一条，两种写法可混用：

- **含点号 = 域名**：`bilibili.com` 覆盖全部子域（www/space/message/passport…），边界安全——不误伤 `notbilibili.com`、`bilibili.com.example.com`
- **不含点号 = 关键词**：主机名包含该词即命中（`bilibili` 同时覆盖 bilibili.com / bilibili.tv 等跨后缀站群）；代价是含词的第三方域名也会被约束
- 只看主机名，URL 路径与搜索参数不参与

## 安装（约 1 分钟）

1. 下载：`git clone` 本仓库，或 Code → Download ZIP 解压
2. 打开 `chrome://extensions` → 右上角开启**开发者模式**
3. 点**加载已解压的扩展程序**，选择本目录（`manifest.json` 所在层）
4. 点击工具栏里的 WhyTime 图标打开设置页，把你想限制的网站写进名单

> 同样适用于 Edge（`edge://extensions`）等 Chromium 浏览器。安装后记得先去设置页：**名单、续时次数、替代动作、睡觉锁定**都在那里。

## 建议的用法

1. **名单只放真的想限制的站**，别把工作必需的站也放进来
2. **原因写具体**："查资料"不算，"搜索 PsychoPy 定时实验怎么写"才算——具体到动作，承诺才有约束力
3. **拿不准就选短档**：到期可以结束再开一场（有冷静期），多出来的时间容易让人跑偏
4. **"接下来去"填一个真实去处**：做完就去那
5. **每周看一次导出的 CSV**：计划 vs 实际的差距，就是你对时间的预估误差——它是可以训练出来的

## 数据导出与 CSV 字段说明

历史页可导出 JSON（完整字段，含逐次续时承诺、对齐检查作答等）与 CSV（19 列，UTF-8 BOM，Excel 直接打开不乱码）。

| 列 | 含义 |
|---|---|
| `id` | 本次使用的唯一标识 |
| `site` | 名单中命中的站点（Session 身份恒为名单条目本身，不是入口子域） |
| `start` / `end` | 开始 / 结束时刻（本地时间；到期自动归档时 end = 结算时刻） |
| `plannedMinutes` / `plannedSeconds` | 承诺时长（含续时追加） |
| `actualMinutes` / `actualSeconds` | 实际用时。墙钟口径：结束/结算时刻 − 开始时刻；到期自动归档封顶于"预算结束 + 5 分钟"（离线时间不计费） |
| `purpose` | 使用目的（工作/学习/信息查询/社交/娱乐/放松/其他） |
| `reason` | 你写的具体原因 |
| `extensionCount` | 续时次数 |
| `endKind` | 结束方式：`user` 主动结束（计时条 × / 对齐检查中结束 / 到期页结束）；`expiry` 到期；`curfew` 宵禁强制结束 |
| `status` | 归档记录恒为 `ended`（进行中的使用不入统计） |
| `breaks` | 本次使用触发的强制拉伸次数 |
| `checkIns` | 目的对齐检查的作答次数 |
| `inconsistent` | 其中回答"不一致"的次数 |
| `deviations` | "不一致但写理由继续使用"的原因合集（` \| ` 分隔） |
| `reviewDeviated` | 到期偏离回顾：是 / 否 |
| `reviewReason` | 回顾时填写的偏离原因 |

两条归日规则（影响按天汇总）：

- **实际用时**按本地午夜切分归属（跨 0 点的一场使用拆给两天）
- **打开次数 / 续时次数 / 计划时长**归属开始的那一天

> "接下来去"（nextAction）暂不进 CSV，JSON 导出中包含。

## 隐私

- **一切数据只存在你浏览器的 `chrome.storage.local` 里**：使用记录、承诺理由、导出文件，都不过任何服务器
- 权限只有 `alarms` 与 `storage`，扩展不发起任何网络请求
- 代码无依赖、无构建、无上报逻辑，可以全部读完再装

## 开发

- 零依赖、零构建：改完代码在 `chrome://extensions` 点"重新加载"即生效
- 核心代码分布：`background.js`（Session 状态机与消息分发）、`blocked.js`（阻断页各视图）、`content.js`（计时条与页面判定）、`wt-util.js`（名单匹配与默认值）、`wt-stats.js`（统计与导出，纯函数）
- 架构要点：`chrome.storage.local` 是唯一权威状态；计时权威 = `plannedEndTime` 与 `Date.now()` 比较（`chrome.alarms` 兜底），不依赖页面存活；`blocked.html` 是唯一阻断层，跳转只由 background 执行，返回地址经一次性令牌签发、绝不进 URL 参数

## 路线图与已知取舍

- 墙钟口径为有意选择：暂不做 active-tab / idle 心跳的"精确计时"（Phase 2 方向）
- 进行中的使用不入统计页；到期归档宽限固定 30 分钟
- 仅限 Chromium 系浏览器；Firefox 适配在路线图中
- 暂无 popup、暗色模式与多语言
